# SylesStacks Apps

**Official application repository for SylesStacks Mobile.**

This repository stores Android APK releases used by the SylesStacks application store.

## Features

- APK file hosting through GitHub Releases
- Application version management
- Release descriptions
- Download statistics
- Automatic APK catalog integration with SylesStacks Server

## How to publish an application

1. Open the Releases section.
2. Select **Create a new release**.
3. Enter a version tag, for example `v1.0.0`.
4. Attach the APK file.
5. Publish the release.

SylesStacks Server automatically detects APK files attached to published releases.

## Repository structure

```text
SylesStacks-Apps/
├── README.md
└── Releases
    ├── Application APK files
    └── Version information
```

Only applications that you own or have permission to distribute may be published here.
